## Problema
Hero section failed 3 times → project killed. Builder agent produces technically correct but visually generic output. Stacking CSS techniques (layered planes, back-type, grain, vignette) != good design. Stock photos feel fake. The builder follows the cinematic description literally but misses the FEELING.

## Resolución
Project stopped by user.

## Prevención
1) Builder must self-screenshot AND honestly compare to reference — if it doesn't match the reference's quality level, DON'T ship it. 2) Start with the SIMPLEST beautiful hero, add ONE element — not 5 layers from the start. 3) Never use random Unsplash stock photos — either use project-specific mockups or use an abstract/atmospheric approach. 4) The reference comparison gate must be HONEST — "does this look as good as griflan?" not "did I check all the boxes?"
